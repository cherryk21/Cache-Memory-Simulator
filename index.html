Cache Mapping Techniques

Select a mapping technique for your simulation.

01

Direct Mapping

Each memory block maps to exactly one cache line using a fixed mapping formula.

02

Fully Associative

Any memory block can occupy any cache line. Uses FIFO replacement when the cache is full.

03

Set Associative

Memory blocks map to a particular set and can occupy any way within that set.
